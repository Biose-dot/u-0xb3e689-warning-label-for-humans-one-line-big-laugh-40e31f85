[Warning Label for Humans: One Line, Big Laugh](https://make.fun/c/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).

A label that reads like a real safety warning, with the laugh landing in the last clause: the danger is not the human, it is asking twice.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> WARNING: This human runs on caffeine, spite, and four hours of sleep. Do not shake, do not update before coffee, and never ask twice if they are okay.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
