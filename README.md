Entry for the [make.fun](https://make.fun) bounty
[Warning Label for Humans: One Line, Big Laugh](https://make.fun/c/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).

A label that reads like a real safety warning — 'contents under pressure' — with the laugh landing in the last clause: the danger is not the human, it is asking twice.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> WARNING: Contents under pressure: one human, powered by caffeine and spite, running on four hours of sleep. Do not shake. Do not ask twice if they are okay.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
